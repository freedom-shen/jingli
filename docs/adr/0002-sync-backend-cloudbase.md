# ADR-0002：同步后端从 LeanCloud 换成微信云开发

- 状态：提案（待作者确认）
- 日期：2026-11-15
- 决策者：项目作者

## 背景

原方案 [docs/leancloud-sync.md](../leancloud-sync.md)（v2，2026-11-05）选 **LeanCloud 开发版**作为单一数据源 hub；P1 本地变更层已实现，并随 v0.6.49 / v0.6.50 发布。

2026-11-15 复核后端可行性，发现两处硬约束，都必须先解决：

1. **LeanCloud 正在停服**。官方公告（[关于 LeanCloud 停止对外提供服务的通知](https://docs.leancloud.cn/sdk/announcements/sunset-announcement/)）：
   - **2026-01-12** 起停止新用户注册、停止创建新应用；
   - **2027-01-12** 正式停止服务，之后应用访问、数据读写、API 调用全部关闭，留存数据将销毁。
   - 也就是说：现在既开不了新应用，即使已有应用也只剩约两个月寿命。LeanCloud 不能作为长期后端。

2. **微信小程序调外部域名必须备案**。小程序的 `request 合法域名` 要求 HTTPS 且域名已 ICP 备案；体验版在真机上同样校验（开发者工具可临时勾「不校验合法域名」、真机预览可「打开调试」跳过，但日常用的体验版不能依赖这个）。
   - LeanCloud 官方 FAQ（[域名绑定常见问题](https://docs.leancloud.cn/sdk/domain/faq/)）明确：开发版应用无法由 LeanCloud 协助备案；想备案需**自行购买独立 IP** 再工单接入；商用版最低 30 元/天。
   - 即使 LeanCloud 不停服，这条路对「自用体验版」也过重。

## 决策

把同步后端从 LeanCloud 换成 **微信云开发（CloudBase）**：

- **小程序端**：`wx.cloud` SDK 直接读写云数据库 / 调云函数，**不需要配置服务器域名、不需要备案**，体验版可用。
- **Mac 端**：走云开发 **HTTP API**（`api.weixin.qq.com/tcb/...`，用小程序 AppID + AppSecret 换 access_token），不需要自建域名、证书和服务器。
- **存储模型沿用 P1 设计**：云端只存 append-only 的 `JingliChange` 变更日志（外加 `JingliSnapshot` 快照），不做合并；各端按 `(entity, entityId, field)` 取最大 `rev` 归并。P1 已实现的 `sync_change` / `SyncStore.apply` / 字段级 LWW 全部不变。
- **小程序工程**独立于 Swift 代码，放在仓库 `MiniProgram/` 下；仓库里不放任何密钥。

## 理由

1. LeanCloud 停服是硬约束，没有讨论空间。
2. 云开发对「个人自用 + 体验版 + 不上线」几乎零门槛：免费环境、无域名、无备案、无服务器、无运维。
3. 个人主体小程序可以使用云开发（个人小程序暂无微信认证限制）。
4. P1 的合并协议与云端实现无关，换后端不影响已发布的本地变更层和测试。
5. 免费额度对个人用量（一天几十次读写）富余几个数量级。

## 后果

### 正面

- 不买域名、不备案、不买服务器：在免费环境政策内成本为 0。
- 小程序端零网络配置，体验版直接可用。
- 数据在腾讯云国内节点，手机和 Mac 访问都稳定。

### 负面 / 约束

- 云开发免费环境是「开发阶段免费」活动（2025-02-19 起）：未上线小程序免费，**活动截止 2026-12-31**；之后可能改为付费（基础套餐约 19.9 元/月起，以官方为准）。届时可选：付费、或迁到自建服务。
- 免费环境有未明示的功能限制；`api.weixin.qq.com` 的云开发 HTTP API 在免费环境下是否可用，必须实测（见 [操作清单 V2](../miniprogram-setup.md)）。
- Mac 端需要保存 AppSecret（Keychain / 仓库外配置）；AppSecret 等同小程序后台权限，必须按密码对待。
- 小程序端写入建议走云函数（管理端权限），而不是客户端直写数据库，多一层代码和部署。

## 备选方案

- **自建服务**（已有 war3rank 服务器 + 已备案域名）：数据完全自控、无额度焦虑；但需要已备案的 HTTPS 域名，且服务器要承担可用性和备份，工作量最大。
- **Gitee 私有仓库 JSON + PAT**：免费、自带 git 版本历史；但小程序要把 `gitee.com` 加进 `request 合法域名`，并发只能做简单版本号，没有查询能力，每次全量拉取。
- **LeanCloud**：已否决——停服 + 小程序域名备案两个硬约束。
