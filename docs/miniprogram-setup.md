# 微信小程序 + 云开发：操作清单

状态：待执行（2026-11-15 整理）。
目标：在微信小程序里「看今天 / 快速加任务 / 勾完成 / 改备注」，与 Mac App 双向同步。
前提：**只自用、不上线、不发布**，用个人主体 + 体验版；不买域名、不做备案、不买服务器。
配套决策：[ADR-0002：同步后端从 LeanCloud 换成微信云开发](adr/0002-sync-backend-cloudbase.md)。同步协议仍见 [leancloud-sync.md](leancloud-sync.md)（传输层已按云开发调整）。

## 0. 结论先行

- **LeanCloud 方案作废**：官方已于 2026-01-12 停止新注册/新建应用，2027-01-12 全面停服。原 `docs/leancloud-sync.md` 里的 LeanCloud 传输层不再实施。
- **小程序不能直接调未备案域名**：`request 合法域名` 要求 HTTPS + ICP 备案，体验版在真机也校验。所以「LeanCloud / 自建服务」都得先解决备案。
- **云开发是最短路径**：小程序端 `wx.cloud` 不需要任何域名配置；Mac 端走 `api.weixin.qq.com` 的云开发 HTTP API，也不需要自备域名。免费环境在「未上线」阶段免费。

## 1. 你要做的（约 1 小时）

### 1.1 注册小程序（约 30 分钟）

准备：一个**没注册过公众平台**的邮箱、身份证、手机、微信。

1. 打开 [mp.weixin.qq.com](https://mp.weixin.qq.com) → 立即注册 → 选「小程序」。
2. 邮箱激活 → 主体类型选「**个人**」→ 填身份证信息、管理员微信扫码、手机验证。
3. 注册完记下 **AppID**：开发 → 开发管理 → 开发设置。
4. 填基本信息：名称（准备 3–5 个备选，名称全网唯一）、头像、简介、服务类目选「工具 → 效率」。
   - **不要提交发布/审核**；个人主体做开发版和体验版足够，不用做微信认证。
5. 管理 → 成员管理 → 确认自己（管理员）在列；体验成员后面再加自己即可。

### 1.2 开通云开发（约 10 分钟）

1. 微信开发者工具（本机已装 2.01.2602032）扫码登录；新建项目时填上面的 AppID。
2. 工具左上「云开发」→ 开通 → 选带免费额度的环境，记下 **环境 ID**（形如 `jingli-1gxxxxx`）。
3. 云开发控制台 → 数据库 → 新建集合：`jingli_change`、`jingli_snapshot`、`jingli_meta`。
4. 开发管理 → 开发设置 → 小程序密钥 → 生成 **AppSecret**（只显示一次）。
   - **不要发在对话里，不要提交进 git**。存 1Password；联调时我把它写进仓库外的 `sync.plist` + Keychain（`secrets/` 已在 `.gitignore`）。
5. 顺手看一眼「云开发 → 设置 → 套餐/资源」：确认是免费环境、到期/续费说明截个图。

### 1.3 体验版流程（我写完小程序代码后，约 10 分钟）

1. 我把小程序代码放进仓库 `MiniProgram/`，你在开发者工具里打开它（用你的 AppID）。
2. 工具右上「上传」→ 填版本号。
3. 公众平台 → 管理 → 版本管理 → 把刚上传的版本设为「**体验版**」。
4. 手机微信扫体验版二维码（或从「最近使用」打开）；首次会提示加入体验成员。
5. 以后每次更新：我改代码 → 你「上传 → 设为体验版」，手机上重新打开即可。

## 2. 我后续要做的（代码，账号就绪后开工）

- **P2'（Mac 端）**：「Mac 同步引擎」从 LeanCloud REST 改为云开发 HTTP API：
  - AppID/AppSecret/环境 ID 从仓库外 `sync.plist` + Keychain 读；缺失时同步禁用，不影响本地功能；
  - access_token 获取 + 缓存 + 过期重取；
  - 批量写 `JingliChange`（每批 ≤ 100）、按服务端时间戳拉取（2 分钟重叠 + `changeID` 去重）、`JingliSnapshot` 上传；
  - 设置页「同步」区块：状态、上次同步时间、「立即同步」、配对信息；
  - 单测用 mock HTTP，不写真 key。
- **P4'（小程序端 MVP）**：今日列表、快速加任务（默认今日；可选项目）、勾完成、备注；首屏快照 + `onShow` 增量拉取；写入走云函数。
- **首次迁移**：以本机为 canonical，全量推送一次；再验证第二台 Mac / 手机。
- **验收**：Mac 加任务 → 小程序看到；小程序加任务 → Mac 看到；离线改动回来不丢；删除不复活。

## 3. 账号建好后先验证这 3 件事（10 分钟）

- [ ] **V1 免费环境**：云开发能创建免费环境，且套餐页写明「未上线阶段无需续费」。
- [ ] **V2 Mac 走 HTTP API**：用 AppID + AppSecret 换 access_token，调一次云开发接口（`invokeCloudFunction` 或数据库接口）返回 `errcode: 0`。我写 20 行脚本验证。
- [ ] **V3 体验版真机**：体验版里 `wx.cloud` 能调通（不需要任何域名配置）。

V1/V2 任一不成立 → 改走备选：自建服务（需已备案 HTTPS 域名）或 Gitee 私有仓库 JSON。

## 5. 纪律

- AppID 可以进仓库；**AppSecret、access_token 不进仓库**，存 Keychain / 仓库外配置。
- 单元测试与截图全部用 mock，不写真 key。
- 不上线、不发布、不接支付；`request` 合法域名一个都不用配。
