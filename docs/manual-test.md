# 手工验收清单

自动化覆盖不到的部分，发版前逐项过一遍，并把证据（截图 / 日志 / 时间）记在下面。

## 勿扰（需要先创建两个快捷指令）

按 `docs/focus-shortcuts.md` 创建 `Jingli Focus On` / `Jingli Focus Off`。

- [ ] 开始番茄钟 → 控制中心显示勿扰；`shortcuts run` 无报错。
- [ ] 暂停 → 勿扰保持。
- [ ] 完成 / 废弃 → 勿扰退出。
- [ ] 开始休息 → 勿扰退出；再来一轮 → 重新进入。
- [ ] 退出 App → 勿扰退出。
- [ ] 开始前已有「工作」Focus → App 不接管，结束后原有 Focus 仍在。
- [ ] 未创建快捷指令时，设置页显示「未配置」，计时不受影响。

## 通知

- [ ] 首次开始番茄钟弹出授权，选择「允许」。
- [ ] 轮次结束出现横幅，标题「本轮番茄钟完成」。
- [ ] 系统设置 → 通知 中能看到「精力管理」。
- [ ] 若曾被拒绝：系统设置中改回允许后重试。

## 全局弹窗 / 浮窗

- [ ] 主窗口关闭、App 在后台时，完成弹窗仍出现在最前面。
- [ ] 全屏应用（如 Keynote / 视频）之上仍可见。
- [ ] 多 Space：切到任意 Space 都能看到浮窗与完成弹窗。
- [ ] Stage Manager 下可见。
- [ ] 浮窗拖动后重启 App，位置保持；把位置拖到屏幕外不会丢失（回退默认）。

## 睡眠 / 唤醒

- [ ] 计时中合盖 / `pmset sleepnow`，唤醒后剩余时间正确（按 `endsAt` 恢复）。
- [ ] 睡眠跨过结束时间：唤醒后直接进入完成态，统计只记一次。
- [ ] 计时中强制退出 → 重开恢复剩余时间；跨过结束时间的状态正确。

## 完整一天（dogfood）

- [ ] 真实 25 分钟至少 4 轮，其中至少 2 轮共享（2–3 件任务）。
- [ ] 至少 1 次中途加任务、1 次移出任务。
- [ ] 完成任务后卡片置灰划线，主线名额仍占用；重置一天后回到开启一天。
- [ ] 统计页数字与手记一致（番茄数、时长、完成任务）。
- [ ] 跨零点开着 App：次日自动清空昨日番茄，未完成任务回未安排，已完成保留。
- [ ] 无数据丢失、无崩溃、计时误差 < 1s。

## 备份 / 恢复

- [ ] 设置 → 立即备份生成 `Backups/jingli-YYYY-MM-DD.json`。
- [ ] 导出 → 换一个 `JINGLI_SUPPORT_DIR` 导入 → 项目 / 任务一致。
- [ ] 导入不覆盖今日番茄记录。

## 发布

- [ ] Release 构建通过，图标正常。
- [ ] 干净机器 / 新用户打开无崩溃。
- [ ] `CHANGELOG.md` 与版本号一致。
